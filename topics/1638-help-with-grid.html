How can i marked the current cell with color ?

There is no chance at this time to change the background color of different cells in the OpenDCL built-in grid control. Some are using flexgrid ActiveX control. Unfortunately, I have no experiences in flexgrid control.

"event invoke" = 1 , to send command to autocad , its very slow ?

No, it's not very slow, but it may be that the command only will executed after the palette will return the control to AutoCAD. In KeepFocus-mode you cannot made all changes properly in the drawing. To do this AutoCAD needs full control. That's why the latest event has to be finished before starting your changes.
I'm using palette, too. I call all administrative tasks (like changes in the external databases or on the form) with eventinvoke=0 and only if user inputs are needed or anything has to be drawn or created in the drawing I start a command using eventinvoke=1. In the OpenDCL documentation it is explained very well ({2}).

I hope, this helps a bit.
