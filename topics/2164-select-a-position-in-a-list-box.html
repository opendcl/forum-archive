for now I solved using a loop to find the position I seek
(setq cont -1)
    (while (/= (dcl-ListBox-SelectString TopoWAR/form_exp/formato (setq formato_t (nth formato_n formato)) cont) formato_n)
      (setq cont (1+ cont))
    )
