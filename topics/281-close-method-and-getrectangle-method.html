owenwengerd 2008-04-11 00:18 UTC
GetRectangle returns coordinates in the parent window's client coordinate system, and Close returns coordinates in the screen coordinate system. If the AutoCAD main window is maximized, this would mean the coordinate systems are identical for e.g. modal dialogs, but if the AutoCAD main window is not maximized, the coordinate systems would be different.
