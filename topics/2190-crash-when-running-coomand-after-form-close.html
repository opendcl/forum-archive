owenwengerd 2014-11-11 02:24 UTC
This has been discussed frequently here in other threads (e.g. {2}). You cannot safely call (command) from an event handler of a modal dialog. Just move that code to your main function so that it executes after (dcl-Form-Show) returns, then it will work fine.
