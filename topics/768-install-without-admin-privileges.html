fred_tomke 2009-05-25 06:48 UTC
Hi, Forest,

the thing is: you should not try to simply copy the files into the application folder.

Why not? It's much more easy to call the runtime msi and the installation script decides which arx has to be loaded in which AutoCAD release.
Next thing is, if two or more applications are installed and all of them are using OpenDCL, there won't be any trouble between different OpenDCL releases.
OpenDCL sets the information about the localization which is used.

The much bigger reason is, if the administrator forces the clients not to install additional software, then you should keep your hands from it without having permissions to do that. I already have my experiences in that, believe me.
