I have a dialogue where the "imagelist" of the Grid is set to "Width: 32 / height: 32" - both greyed out and fixed.
Another dialogue is "16 * 16", greyed out too?

Where does the size comes from?
Can it be modified?

- Solution(?) -:
It seems that the size of the first image which is imported to a new, empty image-list defines and fixes the values.
They can not be modified later, but you can delete all images from the list and import them again, considering the size of the first image.
