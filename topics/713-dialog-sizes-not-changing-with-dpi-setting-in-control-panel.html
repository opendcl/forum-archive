owenwengerd 2009-04-10 14:20 UTC
Unfortunately OpenDCL sizes dialog boxes and controls by pixels instead of "logical units".  As long as font sizes are set to "Font Size in Pixels", they will remain proprtionally correct to the controls. I'd like to change OpenDCL in the future to interpret all sizes as logical units (same as "Font Size Scaled to Monitor"), but for now I'm afraid you're stuck with the current design.
