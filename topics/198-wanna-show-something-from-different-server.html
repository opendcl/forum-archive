bazzacad 2008-02-20 04:53 UTC
OK I got it now, just a simple setting bared in all the forum config screens.
However when you produced your Camtasia file you had it create a web page so it's looking for an XML file and wont play without it.
You need to produce it as a stand-alone flash file like this....
So it has the controls embedded & you can play it.

[flash=640,480]http://www.opendcl.com/site/flash/AR.swf

So the string is:
[_flash=640,480]http://www.opendcl.com/site/flash/AR.swf
(Without the first "_")
