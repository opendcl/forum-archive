owenwengerd 2014-10-20 16:14 UTC
A repair install of OpenDCL Runtime is the only thing needed after installing a new version of AutoCAD.
khann 2014-10-21 02:47 UTC
Hi, Owen.
You mean that every new install of AutoCAD needs repair install of OpenDCL?
Even the same version of AutoCAD?
owenwengerd 2014-10-21 03:17 UTC
Yes, because the OpenDCL Runtime installer creates the needed demand-load registry keys. It can only create those keys if the corresponding version of AutoCAD is already installed. Therefore, installing a new version of AutoCAD (or any intervening action which removes the demand-load registry keys of a previously installed AutoCAD) requires the OpenDCL installer to run again. This can be accomplished with a repair install of OpenDCl Runtime.
