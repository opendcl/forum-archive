Hi, Owen,

In my experience with ObjectDCL DisplayBlock loads the given block before setting the view. When having huge blocks it could cause a delay when changing the view.
But while I'm creating a sample for you for an other question I feel that DisplayBlock does not reload the block anymore if it is already loaded.
Because I didn't know this before I thought there must be an alternative. But now I know that there's no need for this. And that's ok.
I'll add it to the Migration Guide.
