owenwengerd 2008-11-25 02:57 UTC
Your call to (dcl_FileDlg_GetFileName LispFiles_Form3_MyOpen) occurs after the file dialog is closed.  Once the dialog is closed, LispFiles_Form3_MyOpen is NIL, which triggers the exception you mentioned.

If you want to strip the path and use only the filename, you'll need to do that with AutoLISP by processing the return value from (dcl_Form_Show LispFiles_Form3).

Also, you should modify your *error* function so that it only closes the form if it is open:
(if LispFiles_Form1 (dcl_Form_Close LispFiles_Form1))
