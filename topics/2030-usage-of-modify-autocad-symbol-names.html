owenwengerd 2013-09-23 16:07 UTC
In the English version these menu items are called "Set Lisp Symbol Names" and 'Clear Lisp Symbol Names". If you check the checkbox ("Update all controls on the form" in English) it updates form + controls. If you do *not* check the checkbox, it updates only the form. If the German language version uses unclear terminology, please suggest improvements.
