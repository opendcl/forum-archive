owenwengerd 2008-12-23 03:02 UTC
Be warned that if you install the files manually, you could encounter problems if you also install another application that uses OpenDCL. If a second application installs the OpenDCL Runtime files, and the last one will "win". If you install from the MSI file, Windows manages a reference count for the files in the common files folder so that they can be safely shared by multiple applications and still kept up-to-date.
