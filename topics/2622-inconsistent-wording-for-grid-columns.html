Maybe I'm a the victim of a misunderstanding, but the "Style" of Columns in Grids has for "Style: 0" these descriptions:



a) 0 - Decide at run time (ODCL-Studio, Dropdown)

b) 0 - No style set (ODCL help)

c) 0 - Not editable ("Nicht bearbeitbar", ODCL-Studio German, Dropdown)

a) and b) are rather similar, but c) is completely different - but it seem nevertheless the best description.

So - what's the real behaviour (the best description) of this setting?
owenwengerd 2018-08-08 14:15 UTC
"Not editable" is correct, but sounds too specific to me. The reason such a cell is not editable is because there is no style set, hence no editor defined and no rules to format the content. In other words, a style 0 cell is not inherently uneditable; it just happens that no editor is defined for style 0 cells.

I'm satisfied with the English help, but I suppose the English dropdown could be improved. Maybe "No style (not editable)".
