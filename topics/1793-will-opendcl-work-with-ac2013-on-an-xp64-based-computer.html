I just found an older post were I had the same problem in 2012.
The solution was to manually load the arx file and add it to the startup suite.

It should be here:
c:\Program Files (x86)\Common Files\OpenDCL\OpenDCL.x64.19.arx

Not sure if this is the best fix, but it seems to do the trick....
