owenwengerd 2023-01-21 00:18 UTC
According to {2} the button sends a WM_HELP message to the parent window. Presumably the intent was to trigger the parent form's {2} event handler. The parent form would be the form that is active before the message box is displayed.

I'm not sure it works, though. I see that there is no direct handler for WM_HELP for any of the form types, so it depends on how the MFC dialog code translates an unhandled WM_HELP message.
