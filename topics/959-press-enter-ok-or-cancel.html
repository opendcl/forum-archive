owenwengerd 2009-10-08 13:12 UTC
I suggest to use values for your buttons that are greater than the values for (1) and (2).  In other words, your button handlers should call (dcl-Form_Close N) where N > 2. Then you can easily distinguish the way that the dialog was closed.  will return 1, will return 2, and your button will return N.

If you don't want your dialog to close when the user presses , then handle the ReturnPressed event for the text boxes.
