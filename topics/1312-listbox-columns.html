The problem here is that the description of the MultiColumn property is incorrect in the documentation.  It seems that multi-column has nothing to do with tab stops; rather, it means that the list arranges its items in columns such that once the list is filled to the bottom, the next item is added to a new column at the top of the listbox, and there is no vertical scrolling possible.

I will get the documentation corrected. I don't think there is any way currently to set the width of the tab stops.
