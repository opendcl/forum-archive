Hi, hdLinux, welcome to this forum.
OpenDCL Runtime extends a CAD-platform to allow AutoLisp programs show customized Windows forms for userinterface.
There is at least one requirement for OpenDCL Runtime: the CAD-platform. I cannot reckon the manpower to adapt OpenDCL Runtime to Linux.
As long there is no AutoCAD or BricsCAD running on Linux, there will be no chance for us to try to adapt.
