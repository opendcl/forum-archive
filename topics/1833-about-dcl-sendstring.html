owenwengerd 2012-07-15 17:56 UTC
If you want the function to be executed synchronously, you can just evaluate it directly:

(defun test2()
    (setq a "OpenDcl is too powerful!!")
)
(defun c:test1()
    (test2)
    (setq a "OpenDcl is powerful!!")
)
