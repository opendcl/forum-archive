owenwengerd 2015-11-25 19:10 UTC
It seems to be working as designed. In versions of AutoCAD before AutoCAD 2015, the view render mode was based on the old style built-in render modes. In AutoCAD 2015 and later, the old render modes are mapped now to visual styles, so these views are using the 3D Hidden visual style instead of the old Hidden render mode. I don't think there is any way to set a view to use visual styles in older versions of AutoCAD.
