vosey 2014-10-08 13:33 UTC
Not too sure what happened, but it's now working !  - I restarted the Acad Session and all's fine..
(defun c:rd/Form1/Grid1#OnSelChanged (Row Column /)
(alert (strcat (itoa Row) " - " (itoa Column)))
)
