As Barry has said, if you load the correct runtime your updated project files should work fine. Try manually deleting the old runtime files, then reinstall OpenDCL Studio version 5 and see if that resolves your problem.

If the updated runtime doesn't resolve the problem for you, you can restore the backup of your project file(s). When you save a project from OpenDCL Studio, it creates a .bak file of the previous version of your project. Just rename the .bak file to retrieve it.

This should also serve as a valuable lesson to always work on a copy of the .odcl file when testing alpha or beta builds of OpenDCL Studio.
