Dbl Clicking a control, displayed on a form, opens the control browser. The opening page of the browser displays a definition page showing a list of Properties, Methods, and Events along with a description of the control.

Clicking on items in the tree control at left takes one to a page just for that item. Clicking on the control name that is first in the tree returns one to the opening page. However clicking on any items on the definition page takes one to a dead end from where there is no return to the top page.

Clicking the top node in the tree again does not work either. A workaround is to click on a items below in the tree and then the top node to get back to the main page.

Shouldn't there be some sort of button on the page under the definition page to take one back to where you were in the list, on the definition page?
