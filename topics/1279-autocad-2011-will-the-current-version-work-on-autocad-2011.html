You can have every version of AutoCAD from 2004 to 2011 installed on the same machine & it will run on all of them.
However, you will have to re-install OpenDCL (Runtime or Studio) *AFTER* you've installed a new version of AutoCAD.
Also, you'll need to install the latest development version of OpenDCL for it to run on 2011.
Version 5.1.2.3 will only work up to Acad2010.
