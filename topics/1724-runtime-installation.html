owenwengerd 2011-11-22 22:46 UTC
As Barry said, installing the runtime MSI should enable demand-loading via the OPENDCL command. Did the install finish without errors? If it doesn't work, something is wrong. One posibility is that you've disabled demand-loading of commands (this is set via the DEMANDLOAD system variable). Otherwise, there could be a permissions issue, or a bug in the installer for that matter.

owenwengerd 2011-11-23 01:55 UTC
Take a look in your registry to see if the demand-load keys got correctly installed. Depending on whether you installed for all users or only the current user, it is in either the HKLM or HKCU registry hive under Software\Autodesk\AutoCAD\R18.0\\Applications\OpenDCL. Verify that the value of LOADER points to the correct file. If it does, try loading the file manually by dragging and dropping into the AutoCAD drawing window. If it doesn't load manually, then the problem is with the file, not the demand-loading.
