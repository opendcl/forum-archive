owenwengerd 2021-04-25 13:24 UTC
The (command) function can only run from an existing command context. The usual solution is to create a wrapper command and run it asynchronously by calling {2}; or to set the form's 'Event Invoke' property to asynchronous so the event handler itself runs in command context.
