I was clearing out some old files and directories on the server and came across this: An OpenDCL / AutoLISP / HTML Help file system.  It uses a simple modeless form with an HTML control that dispalys web files.  All the navigation is handle by the HTML files - so anything is possible.  I've included my help file system, which I never finished, but it gives you a good idea of the possibilities.

Hope someone can take this and create something helpful, oops, no pun intended!

Notes:
> Make sure the help files are in AutoCAD's search path. 
> The HTML files use the 'Main.css' file for formating and other HTML stuff
> Help.odcl is the OpenDCL definition file, Help.lsp is the OpenDCL code to transfer into Command_Help.lsp which is where all the runtime code resides.
