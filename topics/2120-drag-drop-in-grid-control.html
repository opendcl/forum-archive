Hello, today I've found a question in my mail about drag&drop in OpenDCL's build-in grid control.
'Cause of missing the known DragDrop events, you can solve that using the mousedown, mousemove and mouseup events.
At least at is as easy to build as with the known DragDrop events of other controls.
Unfortunately, the mouse cursor isn't changing, but maybe it is ignorable for that case.

Have fun to use it.
