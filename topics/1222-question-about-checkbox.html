owenwengerd 2010-05-17 16:02 UTC
I have a theory. Are you starting the command by typing it, then pressing the space bar? If so, try it again but press and hold the space bar, then wait to release it until the dialog is completely displayed. Now when you release it, the check box gets checked because it has focus and "space bar up" translates to toggling the check box state. Is that what you're seeing? You can test the theory by using the key instead of the space bar when starting the command.
