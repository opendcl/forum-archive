Your syntax is incorrect. It should be:
ValueData: {code:myfunction|myargument};

However, your function only appends the argument, so there is no need for it:
ValueData: {code:myfunction}myargument;

Better:
ValueData: {app}\MAyapp r4.0\myargument;
