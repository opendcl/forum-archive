Eine andere Lösung:

1.
Erstelle eine Textdatei:
(setq file (open "MyProject_OdclBase64.txt" "w"))
(write-line (dcl_Project_Export MyProject) file)
(close file)

2.
Benutze vl-get-resource zum Laden:
(if
  (not
    (or
      (dcl_Project_Import (vl-get-resource "MyProject_OdclBase64"))
      (dcl_Project_Load "MyProject" 'T)
    )
  )
  (progn
    (princ "\nError: odcl dialog not found ")
    (exit)
  )
)

3. Die Textdatei kann in eine Des-datei mit kompiliert werden (Project Mode).
